# Minecraft Bounce

A pixel-art dodging game built in a single HTML file. Play as Steve
(or other characters), dodge trees, zombies, skeletons, spiders, endermen,
and creepers, and discover **four hidden easter eggs**.

[▶ Play the game](https://nimblecozmo.github.io/minecraft-bounce/)

## How to play

Open `index.html` in any modern browser, or play online via GitHub
Pages at the link above. The controls are simple:

- **Space / Click / Tap** — jump
- The world scrolls left to right. Survive as long as you can.

## Features

- 4 characters to unlock (click the M in the logo to enable easter eggs)
- 4 hidden easter eggs:
  1. **Diamond Sword** — auto-equips tools to defeat mobs/trees/creepers
  2. **Nuke** — wipes the screen with a particle explosion
  3. **UNO Reverse** — turns skeletons against themselves
  4. **Structure Build** — random Minecraft structures every 50 points
- 14 hand-pixel-art structures (village house, well, church, etc.)
- Custom blood-and-gore toggle in settings
- Local high score persistence
- Press Start 2P pixel font

## No-blood edition

This is the family-friendly edition with no blood, no bonepiles, and
no gore effects. Mobs fall over with white particles, just like the
character death animation. The original edition is in
[the local source](https://github.com/nimblecozmo/minecraft-bounce/blob/main/spec.md)
— see the Settings section for the differences.

## Files
